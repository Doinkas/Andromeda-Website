How To Use Admin

Daily Workflow

  1. Check Site Analytics to see what visitors are clicking.
  2. Use Homepage Media Hub to update homepage messaging.
  3. Use Rosters + Trials and Match Calendar to keep team data current.

Before You Save

  • Keep headlines short and easy to scan.
  • Use clear button text (example: Join Discord, View Schedule).
  • After saving, refresh the public page to confirm updates.
